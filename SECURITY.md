# Security policy · Política de seguridad

Stubbs Jobs stores job-search data, CVs and application packages on the user's computer and runs a local web service on `127.0.0.1`.

## Reporting a vulnerability

Please **do not open a public issue**. Use **Security → Report a vulnerability** in this GitHub repository to send a private report. Include the version, steps to reproduce with fictional data and the impact you observed. You should receive an answer within 14 days.

In scope: the local service (`tools/stubbs_jobs_app.py`), exposure of personal data in downloads or public source, the public job-board reader (`tools/scan_boards.py`), backups and restore, and the Windows launcher.

## Informar de una vulnerabilidad

**No abras una incidencia pública.** Usa **Security → Report a vulnerability** en este repositorio para enviar un informe privado con la versión, los pasos para reproducirlo con datos ficticios y el efecto observado. Recibirás respuesta en un plazo de 14 días.

## Supported versions · Versiones con soporte

Only the latest published release receives fixes. · Solo la última versión publicada recibe correcciones.
